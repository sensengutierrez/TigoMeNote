Dito ilalagay ng GitHub Actions ang release.p12 (signing key ng APK) sa unang build.
Naka-lock ito ng password na nasa GitHub secret na APK_KEYSTORE_PASSWORD lang (wala sa code, notes o chat).
Huwag burahin: kapag nawala ito o ang password, hindi na ma-update ang naka-install na app (kailangang i-uninstall muna).
